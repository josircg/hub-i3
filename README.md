# HUB 3I

[HUB 3I][1] is a web platform to register and maintain Citizen Science initiatives and project in Latin America. 
It is a fork of [EU-CS_platform][2] and it's built with [Python][3] using the [Django Web Framework][4]. 

# Improvements over EUCitizen

* Allows that several editors can edit a specific project
* Administrative Controls Improved 
* Translation tools Improved 
* Map Integration with [Visão][5]
* Newsletter Management
* Forum improved with more moderation controls
* User Guide in Portuguese
