# HUB 3I

[HUB I3][1] O **Hub I3 (HUB 3I)** é um sistema da informação estruturado por ações integradas de pesquisa, desenvolvimento e inovação em informação com o emprego de tecnologias digitais voltadas à elaboração de soluções e recursos digitais que promovam acessibilidade e visibilidade de dados e informações estratégicas para o pensamento crítico acerca das políticas públicas, leis, normas e outros direitos, obedecendo o recorte do ciclo de vida do cidadão e com destaque aos grupos de vulnerabilidade social.

O sistema agrega diferentes tipos de conteúdo associados à política públicas — organizações, projetos, políticas, leis, publicações (incluindo recursos de treinamento), eventos, notícias (blog) e dossiês — com moderação editorial, tradução de conteúdo de domínio, mapas georreferenciados, boletins/newsletters e uma API REST.
 
É baseado na [CÍVIS][2] e é construido na linguagem [Python][3] usando o [Django Web Framework][4].
